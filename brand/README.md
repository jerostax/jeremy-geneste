# Brand kit

Generated by `npm run brand` (`scripts/brand/`): every file comes from the same J and G outlines
of Bricolage Grotesque ExtraBold, optical size 14 (`assets/fonts/BricolageGrotesque-ExtraBold-opsz14-JG.ttf`).
Do not edit these files by hand: change `scripts/brand/brand.ts` and run the script again.
PNGs are rendered by headless Microsoft Edge from WSL (`BRAND_BROWSER` overrides the path).

## Colors

| Token | Hex | Use |
|---|---|---|
| ink | `#0b1220` | Dark background, letters on the accent tile |
| accent | `#6fb2ff` | Primary tile, accents on dark backgrounds |
| paper | `#e9eef6` | Light text and tile on dark or blue backgrounds |
| link | `#1469bc` | Links on white (the accent is too light there: 2.3:1) |

The site serves `app/icon.svg`, `app/favicon.ico`, `app/apple-icon.png` and
`public/brand/jg-mark-email-112.png`, copied here by the script.

## Email signature in Gmail

The signature loads its logo from `https://jeremy-geneste.com/brand/jg-mark-email-112.png`, so the
site must be deployed first.

1. Open `signature-fr.html` in a browser (double-click it).
2. Select everything (Ctrl+A) and copy (Ctrl+C).
3. Gmail → Settings → See all settings → General → Signature → Create new, paste (Ctrl+V).
4. Choose it as the default for new emails and replies, then Save changes at the bottom of the page.
